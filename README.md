# Portfolio
I guess it's my portfolio...

A single-page portfolio website built using HTML, CSS, and JavaScript by Nitin Gulani.

**Live Site:** https://nitingulani.niat.tech/

## What's Inside

- About Me, Skills, Education, and Projects sections
- Dark mode toggle for a better viewing experience
- Responsive design for mobile and desktop screens
- Simple and user-friendly interface

## Run It Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
